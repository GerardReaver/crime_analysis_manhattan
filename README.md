# 🚓 Crime Analysis – Manhattan (NYPD Data: 2024–2025)

## 📌 Project Overview

This project analyzes NYPD crime data with a focus on **Manhattan**, particularly the **9th Precinct**, covering the years **2024 to 2025**. It aligns with my work experience during this period and aims to uncover crime trends, precinct-specific insights, and showcase actionable solutions that were supported by the data.

## 🛠 Tools & Technologies
- `pandasql` (SQL analysis in Python)
- Google Sheets (pivot tables)
- Tableau (interactive dashboards)
- Git & GitHub (version control and documentation)

## 📁 Folder Structure

- 🫧 **Raw Data** – Original data files from NYC Open Data  
- 🧼 **Cleaned Data** – Files after preprocessing and filtering
