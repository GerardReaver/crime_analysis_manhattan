# 📝 Felony Assault — 9th Precinct (2024)

## 📍 Overview

This report focuses on **Felony Assault** incidents reported within the **9th Precinct** of Manhattan during the **2024 calendar year**. It is part of a broader effort to identify, analyze, and address crime patterns in Manhattan using real NYPD complaint data.

The data used here was filtered specifically for this felony-level charge category to provide deeper insight into the severity, demographics, and nature of these violent offenses.
